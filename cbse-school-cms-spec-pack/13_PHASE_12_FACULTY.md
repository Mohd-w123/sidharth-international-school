# Phase 12 — Faculty

## Goal
Build dynamic Faculty Management.

## Prompt

Admin can create unlimited faculty profiles.

Fields:
- name
- photo
- designation
- department
- subject
- qualification
- experience
- biography
- display order
- status

Features:
- create
- edit
- archive/delete
- search
- filter
- sort
- pagination

Public:
- faculty listing
- detail page where required
- responsive cards
- filtering where appropriate

Use Media Library for photos.

Do not hardcode teachers. Do not start Phase 13.
