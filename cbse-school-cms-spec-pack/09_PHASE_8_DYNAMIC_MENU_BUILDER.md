# Phase 8 — Dynamic Menu Builder

## Goal
Make header/footer navigation fully CMS-driven.

## Prompt

Admin can create and manage:
- header menu
- footer menu
- secondary menus

Menu item supports:
- internal page link
- custom URL
- external URL
- label
- icon
- ordering
- active/inactive

Support nested menus and mega-menu configuration where appropriate.

Admin can reorder items.

Public header and footer must read menu configuration from the database.

Do not hardcode navigation labels or URLs.

Implement responsive mobile navigation and active states.

Test nested menus, ordering, disabled items, deleted page links, and mobile behavior.

Do not start Phase 9.
