- summary

- featured image
- category
- tags
- publish date
- status
- featured flag

News features:
- CRUD
- search

- pagination
- publish/unpublish
- archive
- public listing

EVENT fields:
- title
- description
- image
- start date
- end date
- time
- location
- registration information
- status

Event features:
- CRUD
- upcoming events
- past events
- public listing
- detail page
- featured events
