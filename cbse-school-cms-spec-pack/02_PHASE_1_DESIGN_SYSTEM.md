# Phase 1 — Design System

## Goal
Build the reusable design system for the public website and admin CMS.

## Prompt

Create an original premium, modern, elegant, academic design system inspired only by the quality of Mayoor School Jaipur.

Use Tailwind CSS, shadcn/ui, and Framer Motion.

Create reusable components:
- Button
- Link Button
- Input
- Textarea
- Select
- Multi Select
- Checkbox
- Radio
- Switch
- Date Picker
- File Upload
- Form Field
- Card
- Badge
- Avatar
- Table
- Pagination
- Dialog
- Drawer
- Sheet
- Tabs
- Accordion
- Breadcrumb
- Dropdown
- Tooltip
- Toast
- Alert
- Confirmation Dialog
- Modal
- Carousel
- Skeleton
- Spinner
- Empty State
- Error State
- Loading State
- Section Wrapper
- Container
- Typography
- Rich Text Renderer

Define typography, spacing, radius, shadows, transitions, responsive breakpoints, animation conventions, public layouts, and admin primitives.

Do not implement business modules.

Run TypeScript, lint, and build. Do not start Phase 2.
