# Phase 4 — Admin Dashboard

## Goal
Build the reusable Admin CMS shell.

## Prompt

Create:
- responsive sidebar
- top navigation
- breadcrumbs
- user profile menu
- logout
- mobile navigation
- page header
- notification placeholder
- dashboard layout

Navigation must be permission-aware.

Create reusable:
- admin page layout
- admin section header
- data table container
- filter bar
- action toolbar
- confirmation dialog
- form drawer/modal

Use real database counts where available for dashboard cards; otherwise use clean placeholders without fake business behavior.

Do not build all business modules.

Run validation and do not start Phase 5.
