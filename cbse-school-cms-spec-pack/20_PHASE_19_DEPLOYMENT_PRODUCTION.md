# Phase 19 — Deployment & Production

## Goal
Prepare the complete application for production deployment.

## Prompt

Review the entire codebase.

Do not introduce new business functionality unless necessary for production readiness.

Check:
- TypeScript
- ESLint
- build
- routes
- environment variables
- authentication
- authorization
- database connection
- Cloudinary
- uploads
- API/server actions
- client/server boundaries

Create production environment documentation.

Document:
- required environment variables
- MongoDB Atlas configuration
- Cloudinary configuration
- deployment configuration
- production build
- initial admin setup
- backup strategy
- rollback considerations

Security review:
- secrets
- authentication
- authorization
- file uploads
- exposed APIs
- sensitive data
- error messages

Review all major public modules and admin modules.

Run:
- TypeScript
- ESLint
- production build
- available tests

Fix production-blocking issues.

Do not claim production readiness unless checks actually pass.

Provide final report:
1. Architecture summary
2. Completed modules
3. Database summary
4. Authentication summary
5. CMS capabilities
6. Public website capabilities
7. Admin capabilities
8. Environment variables
9. Deployment procedure
10. Backup procedure
11. Known limitations
12. Future recommendations

This is the final phase.
