# Phase 13 — Academics

## Goal
Build dynamic academic content management.

## Prompt

Support:
- curriculum
- academic programs
- classes
- subjects
- departments
- academic calendar
- holiday calendar
- timetable
- books/reference material

Admin can create, edit, archive/delete, reorder, and publish/unpublish.

Do not assume a fixed number of classes, departments, or subjects.

Use database relationships where needed.

Public website renders academic information dynamically.

Use reusable tables/forms and Media Library attachments where appropriate.

Do not create a separate Downloads module. Documents should be attached to relevant modules/pages through Media Library.

Do not start Phase 14.
