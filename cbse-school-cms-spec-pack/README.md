# CBSE School CMS — Agent Specification Pack

This folder contains the complete phase-by-phase specification for building the dynamic CBSE School Website and CMS with an AI coding agent.

## How to use

1. Give the agent `00_MASTER_PROMPT.md` first.
2. Then send one phase prompt at a time in numerical order.
3. Do not ask the agent to implement all phases together.
4. After each phase, review its completion report and test the application.
5. Only then send the next phase prompt.

## Important

The website must be completely dynamic. The CMS must be the source of truth for school content.

No Express.js is used. Next.js handles frontend and backend functionality.

The Mayoor School Jaipur website is a design reference only. Do not copy its assets, content, code, or branding.
