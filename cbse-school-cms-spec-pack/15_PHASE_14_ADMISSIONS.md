# Phase 14 — Admissions

## Goal
Build dynamic Admissions management.

## Prompt

Admin can manage:
- admission process
- eligibility
- required documents
- fee information
- important dates
- admission instructions
- admission-related content

Create public admission pages.

Prepare integration with the Dynamic Form Builder for admission enquiries/applications. If the Form Builder is not yet implemented, create only a clean integration interface; do not duplicate form architecture.

All admission content and dates must be CMS-driven.

Do not hardcode admission rules or dates.

Do not start Phase 15.
