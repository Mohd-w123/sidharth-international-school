
# Phase 6 — Homepage Builder

## Goal
Build a completely dynamic homepage builder.

## Prompt

The homepage must not be hardcoded.

Admin can:
- add sections
- edit sections
- delete sections
- duplicate sections
- reorder sections
- enable/disable sections
- preview sections
- publish changes

Initial reusable section types:
- Hero
- Announcement
- Introduction
- Principal Message
- Chairman Message
- Statistics
- Programs
- Facilities
- Achievements
- News
- Events
- Gallery
- Video
- Testimonials
- CTA
- FAQ
- Contact CTA

Each section should support appropriate configurable content such as title, subtitle, description, media, buttons, links, background, alignment, items, and ordering.

The public homepage must render from stored configuration.

Do not hardcode homepage structure. The architecture must support adding new section types later.

Add responsive behavior and meaningful animations.

Test admin editing and public rendering. Do not start Phase 7.
