# Phase 5 — Dynamic CMS Engine

## Goal
Build reusable CMS infrastructure for all future modules.

## Prompt

Create reusable patterns for:
- CRUD
- Search
- Filtering
- Sorting
- Pagination
- Bulk Actions
- Status
- Draft
- Published
- Archived
- Slug generation
- Rich text
- Media selection
- Ordering
- Confirmation
- Validation
- Loading states
- Empty states
- Error handling

Create reusable admin data-table patterns, service/repository patterns, Zod validation patterns, React Hook Form architecture, consistent API responses/errors, publish/unpublish logic, and soft-delete logic where appropriate.

The goal is to prevent future modules from implementing CRUD infrastructure repeatedly.

Do not implement News, Gallery, Faculty, Academics, Admissions, Disclosure, Results, TC, or Forms yet.

Test the CMS primitives. Do not start Phase 6.
