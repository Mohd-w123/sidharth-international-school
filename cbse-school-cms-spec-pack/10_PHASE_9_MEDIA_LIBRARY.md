# Phase 9 — Media Library

## Goal
Create a centralized media system.

## Prompt

Integrate Cloudinary.

Support:
- images
- PDFs
- documents
- videos where appropriate

Admin features:
- upload
- preview
- search
- filter
- select
- replace
- delete/archive
- metadata
- folder/category organization

Store appropriate Cloudinary metadata.

Create a reusable Media Picker for:
- Homepage Builder
- Page Builder
- News
- Events
- Gallery
- Faculty
- Admissions
- Disclosure
- Forms where applicable

Validate file type and size and handle upload errors.

Do not duplicate upload logic. Do not start Phase 10.
