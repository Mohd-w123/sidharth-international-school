# Phase 16 — Results

## Goal
Build a completely dynamic Results module.

## Prompt

Admin manages:
- academic session
- class
- result information
- result statistics
- result tables

Do not assume one fixed result structure.

Support configurable result data where appropriate.

Features:
- create
- edit
- archive
- publish/unpublish
- search
- filter
- sort
- pagination

Public:
- result listing
- session filtering
- class filtering
- result details

Reuse the dynamic table architecture from Mandatory Public Disclosure where appropriate. Do not duplicate table logic.

Do not expose unnecessary student personal information.

Do not start Phase 17.
